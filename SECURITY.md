# Security Policy

## Supported versions

Security fixes are intended for the latest version on the repository's default branch. Older builds may not receive updates; use the latest release or build from the current source when possible.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues or pull requests. Use GitHub's private vulnerability reporting feature for this repository when it is enabled. If it is unavailable, contact the repository maintainer privately through the contact information on the repository owner's GitHub profile.

Include the affected version or commit, the Windows version, steps to reproduce, and any relevant impact. Avoid attaching secrets, personal data, or unredacted diagnostic logs. Please allow the maintainer reasonable time to investigate and prepare a fix before making details public.

## Scope

Reports about the Windows Live application, its installer/uninstaller, and its handling of Windows activity or local data are in scope. Issues in third-party dependencies should also be reported upstream when appropriate, with a note to this project if Windows Live is affected.
